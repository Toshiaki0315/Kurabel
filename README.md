# クラベル (Kurabel)

Tauri v2 + Rust + TypeScript (React) で作られた、デスクトップ向けの Diff & Merge ツールです。
2つのファイル／フォルダを左右に並べて比較し、差分の確認・編集・マージ・保存ができます。

## 主な機能

- **入力**: ドラッグ＆ドロップ、またはフォルダアイコンのダイアログでファイル／フォルダを指定
  - 1つだけ開いた場合は、比較せずにそのまま閲覧できます（閲覧専用）
  - 各ペイン右端の ✕ で閉じる、「履歴」から最近の組み合わせを開き直す
- **テキスト比較**
  - 行番号つきの左右2ペイン表示、差分のハイライト（行単位／単語単位）
  - 空白・大文字小文字・空行・コメント（`//`、`#` など、開始文字列は設定可）の違いを無視するオプション
  - 正規表現に一致する行を比較から外す「無視する行のパターン」（例: `^\s*Last updated:`、`\$Id.*\$`）。入力中に、正規表現として有効かどうかを確認します
  - 別の場所へ丸ごと移動した行を検出して、紫色で表示
  - その場で編集でき、入力が止まると自動で再比較。`⌘S` / `Ctrl+S` でカーソルのあるペインを保存
  - 差分ブロックごとの「→」「←」で、反対側へ内容を反映（マージ）。`⌘Z` で元に戻せます
  - 前後の差分へジャンプ（`F7` / `Shift+F7`）、右端の「差分位置バー」で全体のどこに差分があるかを確認・クリックで移動、編集モードでは左右のスクロールが連動
  - シンタックスハイライト（JS/TS・JSON・Rust・Python・C/C++・Java・Go・C#・Swift・Kotlin・シェル・Ruby・SQL・CSS・HTML/XML・YAML/TOML など。ファイルの拡張子から判定）。設定でオフにもできます
  - 空白（`·`）・全角空白（`□`）・タブ（下線）・行末の改行（`↵`）を記号で表示（設定）
  - 行番号を指定して移動（`⌘G` / `Ctrl+G`）。対象は、最後にフォーカス（クリック）した側のペインです
  - 検索（`⌘F` / `Ctrl+F`）と、編集モードでの置換（現在の一致 / すべて）。対象は、最後にフォーカス（クリック）した側のペインです。置換は元に戻せます
  - 「レポートを保存…」で、比較結果を HTML のレポート（左右に並べた全行、差分は色付き）として書き出し
  - 「パッチを保存…」で unified diff 形式（`.patch` / `.diff` / `.txt`）を書き出し
- **3ウェイマージ**: 左・右の2ファイルに、共通の祖先（基準）ファイルを加えて、行単位でマージします
  - 片側だけの変更は自動で取り込み、両側が重なる箇所は「競合」として、左・基準・右の3列で表示します
  - 競合ごとに「左を採用 / 基準を採用 / 右を採用 / 左→右 / 右→左」を選べ、結果は直接編集もできます
  - 結果は左または右のファイルへの上書き、または名前を付けて保存できます（未解決の競合が残る場合は確認します）
- **文字コード**: UTF-8 / UTF-16（BOM対応）/ Shift_JIS / EUC-JP / ISO-2022-JP を自動判定し、保存時は元の文字コードで書き戻します。判定が外れたときは、パス欄の文字コード選択で手動指定して読み直せます。改行コード（LF / CRLF / CR / 混在）も表示します
- **バイナリ比較**: 16進ダンプ＋ASCII を並べて表示し、差分バイトをハイライト（読み取り専用）。大きいファイルは先頭 128KB のみ表示します
- **大きいファイル**: テキストは 1ファイル 16MB まで。画面に見えている行だけを描画するので、数十万行でもスクロールできます
- **zip などのアーカイブ**: 2つの zip（`.zip` / `.jar` / `.war` / `.apk` / `.docx` / `.xlsx` / `.pptx` / `.odt` など）を開くと、中身をフォルダ比較と同じ画面で比較します。サイズと CRC32 で判定するので、展開せずに高速です。中のファイルをクリックすると、その内容をテキスト・バイナリ比較で確認できます（読み取り専用）。1つだけ開いたときは、中身の一覧を表示します
- **フォルダ比較**: 追加・削除・変更をツリーで表示。開閉、状態での絞り込み、名前検索ができ、ファイルをクリックするとその比較画面へ移動します
  - 項目を選んで、反対側へのコピー（フォルダは中身ごと）・削除ができます（上書きと削除は確認つき。削除は完全削除で、ゴミ箱には送りません）
  - 各ファイルのサイズと更新日時を左右に表示し、変更されたファイルは新しい側の日時を太字で示します
  - 「レポートを保存…」で、状態・サイズ・更新日時の一覧を HTML で書き出せます
  - 設定で、除外パターン（例: `.git`、`*.obj`）、サブフォルダを含めるか、比較方法（内容 / サイズと更新日時）を変更できます
- **起動**: コマンドライン引数で比較対象を渡せます（[使い方](#使い方)を参照）
- **安全面**: 未保存の変更があるまま別のファイルを開く・閉じる・ウィンドウを閉じるときは確認を表示

## 開発用コマンド

`make` のターゲットで実行できます。

| コマンド | 内容 |
| --- | --- |
| `make dev` | Tauri アプリを開発モードで起動（初回は Rust のコンパイルに数分かかります） |
| `make web` | フロントエンドだけを Vite で起動（ブラウザ確認用。Tauri の機能は使えません） |
| `make test` | フロントエンド (Vitest) と Rust (`cargo test`) のテストを実行 |
| `make coverage` | カバレッジを測定（フロント・Rust とも 90% 以上が必須） |
| `make app` | リリースビルド |
| `make dmg` | macOS 用の DMG を作成 |

個別に実行する場合:

```bash
npm run test                 # フロントエンドのテスト
npm run coverage             # フロントエンドのカバレッジ
mkdir -p dist && cd src-tauri && cargo test   # Rust のテスト
```

## ビルド

```bash
make app     # 全プラットフォーム共通のリリースビルド
make dmg     # macOS の DMG
```

成果物は `src-tauri/target/release/bundle/` に出力されます。

> 現在、コード署名・公証（macOS）には対応していません。配布する場合は別途 Apple Developer の署名設定が必要です。

## 使い方

1. 左右のパス表示欄にファイル／フォルダをドラッグ＆ドロップするか、右端のフォルダアイコンから選びます
   - 1つ目は左、2つ目は右に入ります。両方埋まっている場合は、ドロップした位置のペインが置き換わります
2. 2つ揃うと自動で比較されます
   - **テキスト**: ツールバーの「編集」で編集モードに切り替えます。ハイライトと行番号は編集中も表示されます
   - **マージ**: 表示モードで、差分ブロックの中央にある「→」（左から右へ）「←」（右から左へ）を押します
   - **保存**: 変更したペインの「保存」ボタン、または `⌘S` / `Ctrl+S`
   - **フォルダ**: ツリーのファイル名をクリックするとファイル比較へ移動し、「← ディレクトリ比較に戻る」で戻ります
3. 3ウェイマージは、2つのテキストファイルを開いた状態でツールバーの「3ウェイ…」を押し、基準（共通の祖先）ファイルを選びます
   - 競合は `F7` / `Shift+F7` で順に移動し、「競合n: 左を採用」などのボタンで解決します
   - 「左へ保存」「右へ保存」「名前を付けて保存…」で結果を書き出し、「← 2ウェイ比較に戻る」で通常の比較に戻ります
4. 「⚙ 設定」（メニューの「クラベル → 設定…」、`⌘,`）で、ハイライト方式、比較時に無視する違い、フォルダ比較の設定（除外パターンなど）を変更できます

### コマンドラインから開く

比較したい2つのパスを引数に渡すと、起動時に左・右へ開きます（1つだけなら左に開きます）。相対パスは実行したフォルダ基準です。

```bash
# macOS（ビルドしたアプリ）
open -a Kurabel --args /path/to/left.txt /path/to/right.txt
# 実行ファイルを直接指定する場合
src-tauri/target/release/kurabel left.txt right.txt
```

開発モードでは `npm run tauri dev -- -- left.txt right.txt` のように渡します。

### キーボードショートカット

| キー | 動作 |
| --- | --- |
| `⌘S` / `Ctrl+S` | カーソルのあるペインを保存 |
| `⌘Z` / `⌘⇧Z`（`⌘Y` / `Ctrl+Y`） | 元に戻す / やり直す |
| `F7` / `Shift+F7` | 次の差分 / 前の差分へ移動 |
| `⌘G` / `Ctrl+G` | 行番号を指定して移動（Enter で移動、Esc で閉じる） |
| `⌘F` / `Ctrl+F` | 検索・置換（Enter / Shift+Enter で次 / 前の一致、Esc で閉じる） |
| `⌘,` | 設定を開く |

### 制限事項

- 読み込めるファイルサイズは1ファイル 16MB までです。差分の計算には 10 秒の制限があり、ほぼ全行が異なる巨大なファイルでは近似の結果になります
- フォルダ比較は 50,000 エントリ・深さ 64 までで、シンボリックリンクは辿りません
- 文字コードの自動判定は推測のため、短いファイルでは外れることがあります（手動で指定できます）
- 空白・大文字小文字の無視は、テキストファイルの比較にのみ適用されます
- フォルダ操作の削除はゴミ箱に送らず完全に削除します
- 3ウェイマージは行単位です。隣り合う行の変更は競合として扱います（git と同様）。3つのファイルを一度にドロップして開くことはできません
- シンタックスハイライトは行ごとの簡易な字句解析です（正確な構文解析ではありません）。2万行を超えるファイルでは行いません
- 空白記号の改行マーク（`↵`）は、すべての行に同じ印を付けます（LF / CRLF の区別はヘッダーの改行コード表示で確認できます）
- zip は読み取り専用です（中のファイルの編集・保存・コピー・削除はできません）。暗号化されたエントリ、シンボリックリンク、16MB を超えるエントリは読めません。2つの zip は、必ずアーカイブとして比較します（バイナリ比較には切り替えられません）
- 画像・Excel・PDF の中身などの比較には未対応です（`.docx` / `.xlsx` は zip として、含まれる XML ファイル単位で比較します）。移動した行の検出は、削除・追加された連続行が完全に同じ場合のみです（編集を伴う移動は検出しません）
- 「無視する行のパターン」は、行全体への正規表現の一致で判定します（置換のように行の一部だけを無視することはできません）。Rust の正規表現エンジンを使うため、先読み・後方参照は使えません
- コメントの無視は行コメントの開始文字列で判定します（`/* */` などの複数行コメントや、文字列中の `//` は区別しません）

## 構成

```
src/            フロントエンド (React + TypeScript)
  components/   画面コンポーネント (テキスト/バイナリ/フォルダ比較、設定ダイアログ ほか)
  lib/          ロジック (マージ計算、ツリー構築、履歴・設定の保存 ほか)
src-tauri/      バックエンド (Rust + Tauri v2)
  src/textdiff.rs   テキスト差分（行/単語、比較オプション）
  src/textcodec.rs  文字コードの判定・変換
  src/binary.rs     16進ダンプ差分
  src/dirdiff.rs    フォルダ比較
  src/merge3.rs     3ウェイマージ（diff3）
  src/compare.rs    パスの判定と比較の振り分け、保存
  src/archive.rs    zip などのアーカイブの一覧・比較・読み出し
  src/fileops.rs    フォルダ操作（コピー・削除）、パッチ・レポートの書き出し、コマンドライン引数の解釈
  src/commands.rs   Tauri コマンド
docs/           開発用ドキュメント（タスク一覧 ほか）
```

## セキュリティ

- Tauri の権限は最小限（`src-tauri/capabilities/default.json`）にしています
- CSP を設定し、テキストの保存は既存の通常ファイルへの上書きのみで、新規作成はしません
- フォルダのコピー・削除は、比較中のフォルダ配下の相対パスに限定し、`..`・絶対パス・シンボリックリンクを拒否します
- 3ウェイマージ結果の「名前を付けて保存」は新規ファイルのみ（既存ファイルは上書きしません）。左右への上書きは確認つきです
- zip の中身は展開せず（ディスクへ書かない）、エントリ名は表示と検索にだけ使います。`..`・絶対パスを含む名前は表示せず、読み出しは 16MB に制限して zip 爆弾を防ぎます
- パッチの書き出しは拡張子を `.patch` / `.diff` / `.txt` に、レポートの書き出しは `.html` / `.htm` に限定しています（レポートに含まれる文字はすべて HTML エスケープし、スクリプトは含みません）
- ファイルサイズ・エントリ数に上限を設けています
