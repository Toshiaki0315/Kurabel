# 開発依頼: Diff & Merge ツール「クラベル (Kurabel)」の実装

本リポジトリ (`https://github.com/Toshiaki0315/Kurabel.git`) は、Tauri v2 + Rust + TypeScriptによるDiff & Mergeツールの初期テンプレートです。
デスクトップアプリとして馴染みやすい、モダンで直感的なUI（カタカナ表記の「クラベル」が持つスマートな印象）を目指しています。
TDD（テスト駆動開発）を前提としており、カバレッジ90%以上を要件としています。
以下の要件に従い、不足しているロジックとUIを実装してください。

## アーキテクチャと技術スタック
- アプリ名: クラベル (Kurabel)
- フロントエンド: React, TypeScript, Vite
- バックエンド: Rust, Tauri v2
- プロセス: TDD (vitest / cargo-llvm-cov カバレッジ90%以上)
- 構成管理: GitHub

## 要求仕様

### 1. 入力インターフェース (ファイル・ディレクトリの選択)
- 比較対象は「Drag & Drop」または「メニュー（ファイル選択ダイアログ）」から指定できるようにする。
- 選択されたものがファイルかディレクトリかを判別し、適切な比較モードに切り替える。

### 2. テキストファイルの比較と編集
- 複数ファイルを選択し、左右（またはペイン）に並べて表示する。
- 各ペインに行番号と本文を表示する。
- 差分箇所をハイライトする。設定によって「行単位」または「単語単位」のハイライトを切り替え可能とする。
- アプリ上で表示中のファイルを直接編集可能とする。
- 編集後、変更内容に基づく「再差分検出」を実行可能とする。

### 3. バイナリファイルの比較
- バイナリファイルが選択された場合、16進数ダンプとASCIIキャラクタ表示の形式で並べて表示する。
- バイナリモードでは、差分部分のハイライトのみを行う（編集機能は不要）。

### 4. ディレクトリの比較 (追加仕様)
- 選択された2つのディレクトリの構造とファイル構成を比較する。
- 左右のツリービュー等でディレクトリ構成を並べて表示し、差分（追加、削除、変更）を視覚的にハイライトする。
- ツリーからファイルを選択した際、対象ファイルのテキスト比較またはバイナリ比較画面を開けるようにする。

## 実装ステップのお願い
1. Rust側でテキスト/バイナリの差分抽出、およびディレクトリ構成のトラバーサル・比較ロジック（Tauriコマンド）を実装し、そのユニットテスト（カバレッジ90%以上）を書いてください。
2. フロントエンド側でDrag & Drop、ダイアログからの選択、ディレクトリ比較用ツリーUI、ファイル比較用エディタUIを実装し、テストを書いてください。
3. Tauriコマンドとフロントエンドの連携部分を実装し、シームレスな操作フローを完成させてください。
