# 開発タスク一覧 (TASKS.md)

このドキュメントは、ClaudeがTDD（テスト駆動開発）で開発を進めるためのステップバイステップのタスクリストです。
各タスクが完了するごとにチェックを入れ、カバレッジ90%以上を維持しながら進めてください。

## Phase 1: Rustバックエンドのコアロジック実装 (TDD)
- [x] `similar` クレートを用いたテキストの差分抽出ロジック（行単位・単語単位）の実装
- [x] `hex` クレートを用いたバイナリファイルの16進数ダンプ＆ASCII変換ロジックの実装
- [x] `walkdir` クレート等を用いたディレクトリ構造の取得とファイル構成の比較ロジックの実装
- [x] パス（ファイル/ディレクトリ）の読み込み・判定ロジックの実装
- [x] 上記ロジックに対するRustのユニットテスト作成（`cargo llvm-cov` でカバレッジ90%以上を確認）
- [x] Tauriコマンド (`#[tauri::command]`) としてフロントエンドに露出させるラッパーの実装

## Phase 2: フロントエンドの基盤構築 (React & Tauri API)
- [x] Tauriの Window API を用いた Drag & Drop によるパス取得の実装
- [x] Tauriの Dialog API (`@tauri-apps/plugin-dialog`) を用いたメニューからのファイル/ディレクトリ選択処理の実装
- [x] 選択されたパスがファイルかディレクトリかに応じて、表示モードを切り替えるルーティングまたはステート管理の実装
- [x] 左右に内容を並べて表示するスプリットペインUIのレイアウト作成

## Phase 3: ディレクトリ比較機能の実装 (追加仕様)
- [x] 2つのディレクトリ構造をツリービュー形式で並べて表示するコンポーネントの作成
- [x] 追加、削除、変更されたファイルを視覚的に区別するハイライト機能
- [x] ツリー上のファイルをクリックした際、ファイル比較モードへ遷移する連携処理

## Phase 4: テキスト比較・編集機能の実装
- [x] テキストを行番号とともに表示するコンポーネントの作成
- [x] 行単位および単語単位での差分ハイライト表示機能（設定による切り替え）
- [x] 表示中のテキストを直接編集できるテキストエリア機能の実装
- [x] 編集内容を一時保存し、「再比較（Re-diff）」を実行するフローの実装
- [x] 関連コンポーネントのVitestテスト作成（カバレッジ90%以上）

## Phase 5: バイナリ比較機能の実装
- [x] 16進数ダンプとASCIIキャラクタを並べて表示する専用コンポーネントの作成
- [x] バイナリ差分箇所のハイライト表示（バイナリモードは編集不可のRead-onlyとする）
- [x] 関連コンポーネントのVitestテスト作成
